# Math Speed Trainer

A lightweight, mobile-friendly mental-maths practice app for Banking, SSC CGL, Railway and other competitive exams.

## Features
- Addition, subtraction, multiplication, division, squares, cubes, square roots, percentages, fractions and mixed operations
- One-, two-, three-digit and mixed difficulty
- Timed and untimed practice
- Instant feedback, score and accuracy
- Mental-maths shortcut library
- Local progress saved in the browser (no account or backend)
- Works as a static website and can be published with GitHub Pages

## Run on Android
1. Download `index.html`.
2. Open it in a modern browser, or publish it with GitHub Pages.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md`.
3. Open **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for the published site link to appear in Pages settings.

## Notes
- This is a starter version. Progress is stored locally in the browser and will not automatically sync between devices.
- This is a practice tool, not an official exam product.
